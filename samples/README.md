# Desktop code samples

`Michael/` and `precision_landing/` are unchanged snapshots from the upstream
BANSHEE repository at the commits listed in the project [README](../README.md).
They require desktop Python and, for several scripts, a camera and flight
controller. They are reference examples, not ESP32 firmware. The known issues
in these scripts are recorded in [the porting audit](../docs/porting-audit.md).

The supported ESP32 starting point is in [`device/`](../device/).
